# Ventilated Brake Disk Air Streamlining Using Curved Vanes
Conducted CFD simulations in ANSYS Fluent to analyze the aerodynamics of ventilated brake discs, aiming to improve vehicle safety and braking efficiency. Compared traditional straight-vane designs with curved-vane geometries, evaluating airflow patterns and cooling performance to enhance thermal management. This was an individual academic project completed as part of the Computational Fluid Dynamics module.
